# TELOS 身份系统（十文件）

用十个 Markdown 文件构建完整个人画像，让 AI 在任何时刻理解用户全貌。每个文件 3–5 句起步，随时间迭代，不求完美。

| 文件 | 内容 | 引导问题 |
|---|---|---|
| MISSION.md | 人生使命 | 我存在的意义是什么？ |
| GOALS.md | 当前目标 | 未来 1–3 年想达成什么？ |
| PROJECTS.md | 进行中项目 | 手上有哪些具体的事？ |
| BELIEFS.md | 核心信念 | 我相信什么是对的？ |
| MODELS.md | 思维模型 | 我用什么框架理解世界？ |
| STRATEGIES.md | 做事策略 | 我倾向用什么方法解决问题？ |
| NARRATIVES.md | 塑造你的故事 | 哪些经历定义了今天的我？ |
| LEARNED.md | 已学的教训 | 从过去错误中学到了什么？ |
| CHALLENGES.md | 当前挑战 | 什么阻碍了前进？ |
| IDEAS.md | 值得探索的想法 | 有哪些值得深入研究的方向？ |

**契约化**：把十文件压成定长约 2,000 token 的机器可读边界声明（如索引文件），作为 Level 4 按需挂载上下文，避免全库常驻稀释注意力。

**命名与存储**：目录扁平稳定；索引用 `∑ 主题.md` 约定；wikilink 用简单格式 `[[笔记名]]`，禁路径格式。
