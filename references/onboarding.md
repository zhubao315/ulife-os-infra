# 入职引导（Audit First）

> 三种入口：新用户 Initialize / 已有系统 Audit / 接入现有 Integrate。

## Starter（默认推荐 · 5 分钟）
只建 4 文件：MISSION + GOALS + PROJECTS + BOUNDARIES + 最小身份契约。
Starter 是**可长期使用的有效系统**，不是失败状态；随时可 `--profile standard` 升级（已存在文件不覆盖）。

## Standard
完整 TELOS 十文件 + 四层记忆 + 基本权限。适合已开始积累知识资产的用户。

## Advanced
完整 uLife OS + MCP + Hooks + A2A + 本地/云端路由。适合有独立服务器与 Agent Runtime 的用户。

## Audit First 流程
1. `ulife.py audit --target <dir>` —— 先评估现状（五层 + NOT CHECKED）。
2. `ulife.py integrate --target <dir>` —— 发现现有资产，生成适配方案。
3. 用户审批后，Evolve 小步升级；**禁止未审计直接新建平行系统**。
