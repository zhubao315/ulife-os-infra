# 可持续改进闭环（Revalidate 引擎 · uLife OS v2.1）

设施不是一次性文档，而是"用 → 测 → 改 → 验 → 回写"的活系统。

## 五步回路
1. **用**：按意图表选一条，真实任务跑一遍（不空转）。
2. **测**：跑 `bash quality_gate.sh` + 记录摩擦点与**返工率（Rework Rate）**——哪步上下文溢出？哪份规范未被检索？
3. **改**：只改现有文件，不新建系统；小步、可回滚。
4. **验**：断链 0 / 锚点 0 / FM 合规 / 标签 0 非标，四项全绿。
5. **回写**：有效改动写回对应章节 + 升级版本；无效尝试标注作废而非删除留痕。

## 成熟度自检（10 项，每月勾一次）
1. TELOS 十文件存在且每季更新
2. 身份契约 ≤2,000 token 且按需挂载
3. 日记 / 回执连续不断档
4. 静默审计脚本全绿
5. uSkill 能力包化（SKILL.md 合规比例）
6. MCP 安全六项全勾
7. A2A 协议接入（进阶）
8. 文档可发现性（意图表覆盖高频场景）
9. 链接健康（断链 0 / 锚点 0）
10. 闭环至少跑过 1 轮

## 质量门命令卡（四项必绿）
```bash
cd /data/obsidian/hermes/09-REFERENCE/93-脚本   # 本库路径；通用环境替换为你的脚本目录
bash quality_gate.sh            # 8 项审计（任何写入后必跑）
python3 link_checker.py --full  # 断链
python3 anchor_lint.py          # 锚点 + 谓词
python3 frontmatter_check.py    # FM
python3 tag_audit.py            # 标签
```
放行标准：**断链 0 / 锚点 0 / FM 合规 / 标签 0 越界**四项全绿。

> **收官期护栏**：若处于交付冲刺期，任何基础设施优化先答「它服务哪项具体交付？」答不出一律冻结——杜绝用打磨工具替代实际交付。

## 维护节律
- 每次改动后：跑质量验证
- 每周：看意图表是否需加新场景
- 每月：跑自检清单，变化写入版本行
- 每季：重审 TELOS + 指南是否匹配业界进展
