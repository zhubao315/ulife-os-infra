# 记忆与上下文工程（热/温/冷 → 四层 + 长时程 · uLife OS v2.1）

## 三层经典模型
- **热 Hot**：当前会话偏好、刚做的决策、即时反馈——短期连贯。
- **温 Warm**：反复工作流、新兴趣、近几周重心变化——趋势与习惯。
- **冷 Cold**：数月到数年关键决策、重大教训、长期偏好——不丢失积累的智慧。

**信号捕捉**：评分反馈、情绪变化、成败结果、明确偏好 → 分类入不同层级，形成持续学习闭环。

## 四层落地映射
| 层 | 载体 | 生命周期 | 手段 |
|---|---|---|---|
| L1 瞬态 | 当前任务沙盒 Scratchpad | 用完即焚 | 防跨任务串味 |
| L2 情景与待办 | 日记复盘 + `Outbox Receipt` 回执 + `Inbox/Pending` 审批队列 | 天–周 | 结构化笔记 + 真实回执校验 + 人机异步审批 |
| L3 语义 | 概念/模型/原则/洞察 | 月–年，只读挂载 | 原生双链 + 索引 |
| L4 程序性 | 验证过的 SOP + 工具契约 | 稳定复用 | Agent Skills |

## 长时程三件套（任务超上下文窗口时）
1. **压缩 Compaction**：近窗口上限时高保真总结、重开新窗口；先最大化召回再提精度；安全轻量法是清 tool 结果。
2. **结构化笔记**：Agent 把进度写到上下文外的 NOTES/待办，后续读回（跨会话连贯）。
3. **子 Agent**：主 Agent 持高层计划，子 Agent 在干净上下文做聚焦探索，只回传 1,000–2,000 token 浓缩结论——隔离的是上下文，不是算力。

**即时检索优先**：持有轻量标识符（路径/查询/URL），运行时按需加载；metadata（目录/命名/时间戳）本身就是信号。
