# 事件钩子（Hooks）

让 AI 从"被动响应"变"主动服务"的"如果…那么…"规则。

## 典型事件
- **会话开始**：加载用户上下文、检查待办、显示今日摘要
- **工具执行前**：验证权限、记录操作意图
- **工具执行后**：捕捉结果信号、更新记忆
- **会话结束**：保存学习成果、生成会话摘要

## 定时/autonomous Agent 可靠性八步
1. 书签偏移读取（不重复不遗漏）
2. 失败显式告警（不静默吞错）
3. 投递前二次复核
4. 回执后才落状态
5. 每轮重读偏好
6. 最小权限
7. 轮次护栏
8. 机器强制层（如 `agent_runtime.py --preflight/--init/--selftest`）

> 写在提示词里只是"建议"，写在代码/磁盘契约里才是"约束"。
