# 用户/系统分离与安全护栏

## 两个目录
- **USER/**：身份、偏好、工作流、技能、钩子、记忆——用户资产，只读保护，更新系统时不覆盖。
- **SYSTEM/**：基础设施代码——可随模型/工具演进热插拔升级。

**六层自定义**：身份（称呼/语气）· 偏好（技术栈/工具）· 工作流（执行模式）· 技能（可用能力）· 钩子（事件响应）· 记忆（什么值得记）。

## 权限验证
每个操作过权限检查；危险操作（删除、外发敏感信息）显式确认；避免"跳过所有检查"的粗暴开关。写 USER 域须显式授权（如 `ULIFE_GUARD_ACK=1`）。

## 确定性护栏
- 可形式化规则用脚本/AST 校验，不依赖模型"自觉遵守"
- 分级门禁：L0 日常直觉 / L1 个人决策 / L2 四步闭环+智囊 / L3 红队+签字（不可逆/关系/大额）
- 一键熔断：红线触发强制暂停；级联断链 >10 处 Abort 回滚
- 外部不可信输入通过准入网关前仅视为 DATA

## 安全目标
保护用户的同时不妨碍工作流——几乎感觉不到存在，但危险面前坚定拦截。
