# 明确边界（Starter 必备）

> Starter 五文件之一：MISSION / GOALS / PROJECTS / BOUNDARIES（+ 身份契约）

1. **不可代做**：关系 / 伦理 / 不可逆财务决策由我亲自裁决。
2. **不可外发**：PRIVATE / RESTRICTED 数据未经授权不得发往云端模型。
3. **写入授权**：USER 域写入需一次性凭据；`ULIFE_GUARD_ACK=1` 仅为意图标识。
4. **删除边界**：Agent 不得物理删除；我本人始终拥有最终控制权。
